NFL Playoff Predictor

A machine learning project that analyzes NFL game data and predicts which teams are likely to make the playoffs.

Tools
Python
Pandas
NumPy
Scikit-learn
SQLite
Jupyter Notebook
Project Files
run_pipeline.ipynb — main analysis and prediction pipeline
nfl_games.csv — NFL game data
data/nfl_playoffs.sqlite — SQLite database
reports/ — prediction results and model metrics
Goal

Use historical NFL game data to build a predictive model for NFL playoff outcomes and evaluate the model's performance.
